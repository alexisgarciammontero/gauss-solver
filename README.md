# Gauss Solver

## Descripción

Proyecto en Java que implementa el método de eliminación de Gauss usando Programación Orientada a Objetos.

## Equipo

* Arquitecto: Alexis
* Desarrollo: Equipo

## Objetivo

Resolver sistemas de ecuaciones lineales comenzando con matrices 3x3 y escalando a NxN.

## Tecnologías

* Java
* Git & GitHub
* Visual Studio Code

## Estructura

* `matriz/` → Operaciones de matriz
* `solver/` → Algoritmo de Gauss
* `sistema/` → Lógica del sistema
* `ui/` → Entrada y salida
* `main/` → Ejecución

## Fases

1. Resolver 3x3
2. Input del usuario
3. Generalizar NxN
